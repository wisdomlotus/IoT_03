1. 오늘의 학습 목표

1주차에는 값을 저장하고, 2주차에는 조건에 따라 판단했습니다. 이번 주에는 그 판단을 반복하고, 기능을 이름으로 묶어 사용하는 방법을 배웁니다.

  1. for와 range()의 반복 횟수와 변수값을 설명할 수 있습니다.
  2. while의 조건 확인과 종료 과정을 따라갈 수 있습니다.
  3. break가 반복문을 끝내는 위치를 찾을 수 있습니다.
  4. 함수의 정의·호출·매개변수·반환값을 구분할 수 있습니다.
  5. import와 time.sleep()의 역할을 설명할 수 있습니다.

이번 주도 코드를 실행하지 않고 읽는 이론 수업입니다. 측정값과 기준은 가상 값이며, 실제 센서 읽기와 장치 제어는 제작 수업에서 배웁니다.

2. 앞선 내용 복습

출력은 기준 이상입니다. 이 코드는 한 번 판단합니다. 같은 판단을 여러 번 하려면 반복문을 사용합니다.

3. 정해진 횟수만큼 반복하기 — for

출력 결과:

for count in range(3):은 count에 값을 하나씩 넣으며 들여쓴 블록을 반복합니다. range(3)에서 사용하는 값은 0, 1, 2입니다.

3-1. range()의 끝값은 포함하지 않습니다

표현반복에서 사용하는 값반복 횟수
range(3)0, 1, 23회
range(1, 4)1, 2, 33회
range(0)없음0회

출력 결과:

화면에는 count + 1을 출력했지만 반복 변수 count에 넣는 값은 여전히 0, 1, 2입니다.

3-2. 조건문도 반복할 수 있습니다

출력은 기준 이상 세 줄입니다. 반복문 안에 조건문이 있으므로 출력문은 두 단계 들여씁니다. 반복문에 들어 있다고 해서 temperature가 자동으로 새 측정값으로 바뀌지는 않습니다. 이 예제는 같은 값을 세 번 판단합니다.

4. 조건이 참인 동안 반복하기 — while

출력 결과:

실행 순서는 다음과 같습니다.

  1. 조건 count < 3을 확인합니다.
  2. 참이면 블록을 실행합니다.
  3. 블록이 끝나면 다시 조건으로 돌아갑니다.
  4. 거짓이면 반복문 뒤의 명령으로 이동합니다.
조건 확인 때의 countcount < 3출력블록 실행 뒤의 count
0True01
1True12
2True23
3False반복문 안의 출력 없음3

조건은 블록을 실행하기 전에 확인합니다. 처음부터 거짓이면 블록은 한 번도 실행하지 않습니다.

종료에 필요한 값 갱신

위 코드에서 count = count + 1을 빼면 count는 계속 0입니다. 조건이 계속 참이므로 반복도 끝나지 않습니다. while을 읽을 때는 “어떤 변화로 조건이 거짓이 되는가?”를 확인해야 합니다.

5. 반복을 즉시 끝내기 — break

출력 결과:

count가 2일 때 break를 실행하므로 그 아래의 print(count)는 실행하지 않습니다. break는 현재 속한 가장 안쪽 반복문을 끝내며, 프로그램 전체를 종료하는 명령은 아닙니다. 반복문 안에서 사용합니다.

보충 읽기: while True

출력은 0, 1, 2입니다. while True는 조건 자체가 계속 참입니다. 이 예제는 내부의 break로 끝납니다. 무한 반복 예제는 실행하지 않고 종료 지점을 읽는 활동으로 다룹니다. 실제로 실행할 때의 중단 방법은 사용하는 개발 환경에서 따로 배워야 합니다.

6. 기능에 이름 붙이기 — 함수

함수는 명령을 하나의 이름으로 묶어 사용하는 방법입니다. 1주차부터 사용한 print()도 함수입니다.

6-1. 정의와 호출

출력 결과:

  • def show_status():는 함수를 정의합니다. 함수에 속한 명령은 들여씁니다.
  • 함수의 본문은 정의할 때 실행되지 않습니다.
  • show_status()로 호출할 때 본문을 실행합니다.
  • 실행을 마치면 호출한 위치의 다음 명령으로 돌아갑니다.

show_status는 이름이고, show_status()는 호출입니다. 괄호 없이 이름만 적으면 함수를 실행하는 호출이 되지 않습니다.

6-2. 함수에 값 전달하기 — 매개변수와 인수

출력 결과:

정의에 적힌 value는 전달받은 값을 사용할 이름인 매개변수입니다. 호출할 때 전달한 25, 28은 인수입니다. 두 호출은 같은 함수에 서로 다른 값을 전달합니다.

이번 예제에서 value는 함수 내부에서 사용합니다. 함수 밖에서도 같은 이름을 자동으로 사용할 수 있다고 생각하지 않도록 주의합니다.

6-3. 결과를 돌려주기 — return

출력은 True입니다.

  1. is_hot(29)를 호출하면 value에 29가 전달됩니다.
  2. 29 >= 28의 결과인 True를 구합니다.
  3. return으로 결과를 호출한 곳에 돌려줍니다.
  4. 반환된 값을 result에 저장합니다.
  5. print(result)가 그 값을 출력합니다.

6-4. 출력과 반환은 다릅니다

  • print()는 값을 화면에 보여 줍니다.
  • return은 값을 호출한 곳에 돌려주고 현재 함수 실행을 끝냅니다.
  • return만으로 화면에 출력되는 것은 아닙니다.

출력은 기준 이상입니다. 첫 번째 return을 실행하면 함수가 끝나므로 그 아래의 return "기준 미만"은 실행하지 않습니다.

7. 만들어진 도구 사용하기 — 모듈

모듈은 다른 코드에서 불러와 사용할 수 있는 기능 묶음입니다. 필요한 모듈을 가져올 때 import를 사용합니다.

time.sleep(1)은 실행 중인 흐름을 약 1초 동안 기다리게 합니다. 화면에는 다음 두 줄이 보이지만 두 출력 사이에 대기 시간이 있습니다.

표현역할
import timetime 모듈을 불러옵니다.
time.sleep모듈 안의 sleep 기능을 가리킵니다.
time.sleep(1)그 기능에 1을 전달하여 호출합니다.

.은 “그 안의 기능”을 찾는 데 사용됩니다. 괄호는 그 기능을 호출하는 표시입니다.

반복 안의 대기 시간 읽기

확인은 3회 출력하고, 대기도 3회 수행합니다. 마지막 확인 뒤에도 기다린 다음 끝을 출력합니다. 의도된 대기 시간의 합은 3초이며, 실제 전체 실행 시간에는 다른 명령을 실행하는 시간도 포함됩니다.

보충 읽기: 제작 코드에서 만날 형태

다음은 문법의 모양을 읽기 위한 예시이며, 이번 자료만으로 실행하는 코드가 아닙니다.

이 형태는 machine 모듈에서 Pin이라는 이름을 가져옵니다. machine은 MicroPython에서 장치 제어에 사용하는 모듈이며 일반 PC의 파이썬에는 기본 제공되지 않습니다.

sensor라는 대상의 read 기능을 호출하는 모양입니다. 이런 기능을 메서드라고 합니다. 실제 센서 읽기 메서드의 이름과 필요한 준비 코드는 키트 라이브러리에 따라 달라집니다. 모든 센서가 read()를 제공한다는 뜻은 아닙니다.
